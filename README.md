# PromptForge AI Studio 🚀

**PromptForge** is a professional-grade, high-performance AI workbench designed for elite creators, developers, and AI engineers. It consolidates 30+ frontier models (GPT-4o, Claude 3.5, Gemini 1.5, DeepSeek R1, etc.) into a unified, modular dashboard, allowing users to leverage the full power of AI without the "Subscription Tax."

![PromptForge Preview](https://images.unsplash.com/photo-1639322537228-f710d846310a?q=80&w=2564&auto=format&fit=crop)

## 🌟 Key Value Proposition
*   **BYOK (Bring Your Own Key):** Connect directly to AI providers (OpenAI, Anthropic, Google).
*   **90%+ Cost Savings:** Pay only for raw API usage. Replace $60/mo in subscriptions with ~$2/mo in API costs.
*   **Model Agnostic:** Switch between models (GPT, Claude, Gemini, Llama, DeepSeek) in the same conversation.
*   **Zero-Trust Privacy:** Your API keys and chat history are stored locally in your browser's encrypted vault. We never see your data.

*   **Multi-Model Integration:** Direct API connectivity for 30+ frontier models.

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/imranah10/promptforge.git
   cd promptforge
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run Development Server:**
   ```bash
   npm run dev
   ```

4. **Connect your Keys:**
   Open the application, navigate to the **API Keys** section, and paste your keys from OpenAI, Anthropic, or Google.

## 🛡️ Security & Privacy
PromptForge is built on the principle of **Client-Side Sovereignty**.
*   **LocalStorage Encryption:** API keys are stored only in your browser.
*   **No Backend Storage:** We do not have a database that stores your prompts or history.
*   **Direct-to-API:** The application communicates directly with AI providers from your machine.
